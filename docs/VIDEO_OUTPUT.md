# SDR, HDR и Dolby Vision

## Поддерживаемая версия mpv

Режимы рассчитаны на portable-пакет mpv.net `7.1.2.0` из `deps.lock.json` с
libmpv из коммита
[`85bf9f4`](https://github.com/mpv-player/mpv/tree/85bf9f4ff46cd45686cfe2fd22f49828877db5cb).
В этом исходнике объявлены
[`target-colorspace-hint-mode`](https://github.com/mpv-player/mpv/blob/85bf9f4ff46cd45686cfe2fd22f49828877db5cb/video/out/vo_gpu_next.c#L216-L218)
и
[`video-target-params`](https://github.com/mpv-player/mpv/blob/85bf9f4ff46cd45686cfe2fd22f49828877db5cb/player/command.c#L4468-L4471).
Другие версии пока не считаются совместимыми. Наличие имён в исходнике не
заменяет физическую проверку вывода на Windows, GPU и дисплее из чеклиста P0.

## Режимы вывода

Настройка `Видео` не определяет формат исходного файла. Она задаёт цель вывода
для текущего экрана:

- `Авто` не меняет настройки mpv.net. При возврате из явного SDR/HDR оно
  восстанавливает значения, сохранённые перед первым явным переключением;
  эта исходная точка сохраняется при смене фильмов до возврата в `Авто`;
- `SDR (Rec. 709)` задаёт `gamma2.2` и `bt.709`;
- `HDR (PQ / BT.2020)` задаёт `pq` и `bt.2020`.

Для SDR и HDR требуется `gpu-next`. CensorPlayer не меняет `vo` сам: это
параметр запуска плеера, и его неожиданная замена во время просмотра опаснее
зелёного кадра. Если активен другой рендерер, свойства видео не меняются, а
плеер показывает понятную ошибку.

Расширение меняет только эти свойства:

```text
target-colorspace-hint
target-colorspace-hint-mode
target-trc
target-prim
```

Настройки tone mapping, peak detection, ICC и `d3d11-output-csp` остаются под
контролем mpv.net и пользователя. После записи свойств расширение проверяет
`video-target-params/primaries` и `video-target-params/gamma`. Если mpv не
подтвердил результат за три секунды, выполняется откат, а сообщение показывает
параметры, которые mpv не подтвердил.

У режима `Авто` нет заранее известной пары primaries/gamma: расширение проверяет
запись каждого восстановленного свойства, но не сравнивает
`video-target-params/*` с фиксированным значением.

## Если Dolby Vision показывает зелёный кадр

Сначала выберите `Авто` и убедитесь, что используется `gpu-next`. Для Dolby
Vision Profile 5 mpv должен выполнить reshape метаданных. Некоторые аппаратные
декодеры или драйверы возвращают кадры так, что этот путь не срабатывает.

В таком случае включите:

```text
Совместимость Dolby Vision (программное декодирование до смены фильма)
```

CensorPlayer временно задаст `hwdec=no`, выполнит `video-reload` и проверит
`hwdec-current`. После смены фильма исходное значение `hwdec` восстановится.
Настройка не записывается в `settings.json`.

Программное декодирование заметно нагружает CPU, особенно вместе с
`lavfi/gblur` на 4K. Если видео начинает пропускать кадры, сначала уменьшите
степень размытия. Постоянное `hwdec=no` в `mpv.conf` для этого не требуется.

## Что означает режим HDR в Windows

Режим `HDR (PQ / BT.2020)` рассчитан на HDR-монитор и включённый HDR в Windows.
На обычном SDR-экране результат может выглядеть блекло или неверно. Для
HDR-фильма на SDR-экране оставьте `Авто`: подходящий tone mapping должен
выполнить mpv.net согласно своей конфигурации.

Режимы не исправляют неверно размеченный файл и не гарантируют поддержку любой
версии Dolby Vision. Диагностический ZIP сохраняет `current-vo`, выбранную цель,
`hwdec` и фактический `hwdec-current`; это первый набор данных для разбора
проблемы.
