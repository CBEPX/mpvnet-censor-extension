# ADR-004: Явный поиск онлайн-таймингов без локального каталога

**Статус:** принято
**Дата:** 19 августа 2026 года

## Контекст

Пользователю удобно начать с готовых таймкодов, если они уже опубликованы.
Однако найденные источники сильно различаются: одни содержат точные интервалы,
другие — только возрастные рекомендации или описание сцен. У большинства нет
лицензии на копирование всей базы. Таймкоды также зависят от версии монтажа.

Локальная база фильмов для этого не нужна. Она вернула бы каталог, миграции и
долговременные связи, от которых проект отказался в ADR-003.

## Решение

1. Первая версия работает только с `timings.rte.net.ru` и использует его
   публичные GET-запросы. Поиск запускает пользователь кнопкой
   `Найти онлайн…`; фоновых запросов нет.
2. Ответ сначала показывается как список кандидатов. Законченные интервалы
   можно добавить в текущий черновик, одиночную отметку — открыть в плеере и
   использовать как начало ручного интервала. Запись `Чисто` не считается
   гарантией отсутствия сцен.
3. Результат относится к текущему `media_session_id`. Смена фильма отменяет
   запрос и запрещает использовать поздний ответ.
4. По умолчанию расширение обращается к `timings.rte.net.ru` напрямую. В
   настройках можно выбрать собственный агрегатор с тем же стабильным API.
   При ошибке агрегатора автоматического перехода на прямой источник нет.
5. Агрегатор — отдельный ASP.NET Minimal API без базы данных, учётных записей и
   методов записи. Он ограничивает частоту запросов и хранит ответ в памяти
   десять минут. Публичная версия публикуется как контейнер, но не развёртывается
   этим репозиторием.

## Границы источников

| Источник | Режим в CensorPlayer | Причина |
|---|---|---|
| timings.rte | ручной импорт кандидатов | Есть публичные GET-методы и таймкоды, но текст свободного формата |
| DoesTheDogDie | ссылка | Точные Scene Alerts требуют отдельного соглашения |
| Unconsenting Media | ссылка | CSV открыт, но лицензия на повторное распространение не опубликована; точные интервалы редки |
| Kids-In-Mind, RunPee, Common Sense Media | ссылка | Нет пригодного открытого API с интервалами цензуры |
| Letterboxd list | ссылка | Условия запрещают автоматическое извлечение; официальный API доступен по заявке |
| Celebrity Movie Archive | скрытая ссылка 18+ | Нет исходных таймкодов и разрешения на копирование данных |
| BMYSTERIO/NC | не используется | Указанный репозиторий недоступен и формат данных нельзя проверить |

Ссылки открываются только после нажатия. Название текущего фильма к ним не
добавляется, поэтому CensorPlayer не передаёт внешнему сайту историю просмотра.

## Последствия

- Пользователь проверяет источник, длительность и монтаж до применения.
- В `*.censor.txt` остаётся обычный переносимый результат с указанием источника
  в примечании; скрытого каталога не появляется.
- Публичность API или CSV сама по себе не считается лицензией. Для
  `timings.rte` разрешение на использование API и работу публичного агрегатора
  получено 19 августа 2026 года; подтверждение хранится вместе с release
  record, а не обязательно в открытом репозитории.
- В первой версии нет универсальной системы плагинов для провайдеров. Новый
  прямой источник добавляется только после проверки API, лицензии и качества
  таймкодов.
